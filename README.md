## Entry

> One star. He pruned me, hugged the cut branch, then spent twenty minutes peeling my sap off his sweater — and STILL calls me 'low maintenance.' I wrote this review in the sap. You're welcome.

## How it works

`main.ts` (Node 22, no dependencies) writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

```sh
node main.ts
```
